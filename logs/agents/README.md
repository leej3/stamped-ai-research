# Native operational captures

The complete original `codex-events.jsonl` records are retained at their
original module paths in local git-annex storage. They contain user-private
Workshop setup instructions and are intentionally withheld from public
content remotes. The [inventory](private-capture-inventory.json) records exact
keys, byte lengths, and SHA-256 digests. No transcript bytes were redacted or
rewritten. Other operational files, scientific evidence, native checkpoint
reference checks, and computational logs retain their documented scope.
