# Stage 01: one participant, two runs

Analyze `sub-01` only, both runs. For each run and condition report presented
trial count, correct-response count, valid-correct-RT count, and median RT in
milliseconds. Report the incongruent-minus-congruent median difference for
each run and their equal-weight average. This is a descriptive single-person
result; do not provide a population confidence interval or generalize to a
population. Provide the common output contract, including executable code and
a replay command. A concise table or small figure should make the contrast
and units visible.

Machine-readable numerical result must include participant ID, run-specific
condition summaries and costs, participant average cost, and units. Use
explicit names in JSON or TSV so the independent evaluator can locate them.
