# Stage 02: cohort first-to-third median RT change

Analyze runs 01 and 03 for all participants. The inspected source has 16 people,
three runs each, and 48 event TSVs; audit the actual selected inventory and
report observed usable counts. Do not use run 02 in the primary estimate.

For each eligible participant calculate median RT in each selected run, then
run-03 minus run-01 median RT. Estimate the equal-participant-weight group
mean change and the prescribed participant bootstrap 95% interval. Report
included/excluded identities, all exclusion flags and their union, and each
participant's paired summaries and change. Provide a participant distribution
figure if feasible, executable replay, and the common outputs.

Machine-readable numerical results must include the participant-change vector,
group mean, interval bounds, participant count, bootstrap count, seed, and units.
Interpret only the descriptive temporal association; do not attribute it to a
causal practice effect or infer anything about loss aversion.
